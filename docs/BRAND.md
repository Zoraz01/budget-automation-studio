# BAS — Budget Automation Studio

BAS is pronounced “bass,” like the fish. The name keeps Budget Automation at its core, with Studio emphasizing customization. Tagline: **Find your financial flow.** Repository: `budget-automation-studio`.

The original emerald fish symbol is built from simple vector geometry in `web/logo.svg`; no external logo or stock asset was used. It follows the existing emerald, near-black and slate palette. The same mark is used for the browser favicon and phone Home Screen icons. Preserve the padded square when generating install icons.

Use BAS for compact navigation and installed-app labels, and Budget Automation Studio in setup and project descriptions. The personal companion may retain its Finance identity; shared mobile components and behavior still follow the parity workflow.

This release updates the public runtime branding and mobile presentation. The 19-screen overhaul and durable chat history remain tracked work; branded design previews are proposals, not proof of backend feature availability.
